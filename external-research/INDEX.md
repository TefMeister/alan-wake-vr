| 2026-09-02 | [The game compiles its shaders at runtime — so `d3dcompiler_43.dll` is a proxy seam](topics/2026-09-02b-the-game-compiles-its-shaders-at-runtime-so-d3dcompiler-is-a-proxy-seam.md) | 🆕 new | ⭐ The game ships DirectX shader-compiler cabs in `third party\directx\` and aborts with **"could not process hlsl shader"** without them — a runtime compiler implies runtime compilation, so there is **no pre-compiled cache to parse** and the `CTAB` trick that answered Alice (45,832 tables) and Enslaved (34,046) does not apply.
